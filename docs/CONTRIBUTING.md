# Contributing Guidelines

## AI-Driven Global Financial Contagion
## and Geopolitical Risk Prediction Engine

Thank you for your interest in contributing
to this research and software project.

The project focuses on quantitative finance,
financial contagion, geopolitical risk,
network science and artificial intelligence.

All contributions should follow scientific,
technical and documentation standards.

---

## 1. Contribution Areas

Contributions may include:

### Research

- Financial contagion research
- Systemic-risk modelling
- Geopolitical risk analysis
- Financial econometrics
- Causal inference
- Network science

### Software Engineering

- Python modules
- Data processing
- Feature engineering
- Model development
- Testing
- Documentation

### Artificial Intelligence

- Machine learning
- Deep learning
- Graph neural networks
- Transformer models
- Multimodal AI
- Explainable AI

### Validation

- Walk-forward testing
- Cross-country evaluation
- Historical crisis replay
- Robustness testing
- Reproducibility
